# Registro de ceremonias Scrum

Evidencia de que las ceremonias ocurrieron, para revisión del profesor de Ingeniería de Software II.

Un archivo por sprint: `sprint-1.md`, `sprint-2.md`, etc. Cada uno debe registrar, por ceremonia:

- Fecha
- Asistentes
- Acuerdos o resultados

## Sprint Review

Qué se demostró, retroalimentación recibida.

## Sprint Retrospective

Cuatro cuadrantes: qué salió bien, qué salió mal, qué se puede mejorar, acciones concretas para el siguiente sprint. Incluir la velocity real del sprint (puntos completados / puntos comprometidos).
